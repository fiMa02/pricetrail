# PriceTrail

Трекер цін супермаркетів з історією цін: пошук товарів, картки з цінами й акціями, графік зміни ціни, перевірка «завищених» акцій. Працює як сайт і встановлюється на телефон (PWA). Зараз підтримується АТБ-Маркет (неофіційно), згодом — інші магазини.

Сайт: https://fima02.github.io/pricetrail/

## Як це працює

```
Планувальник Windows (щодня 05:30) → scripts/daily.ps1 → scraper/scrape.js → site/data/*.json → git push → GitHub Actions → GitHub Pages
```

Ціни збираються **з домашнього комп'ютера**: сайт АТБ (Cloudflare) блокує запити з серверів GitHub (HTTP 403). GitHub лише публікує сайт після кожного push.

- **`scraper/scrape.js`** збирає каталог atbmarket.com окремо для кожного міста зі **`scraper/cities.js`**. Асортимент і ціни залежать від магазину, тому в кожному місті береться один магазин — з найбільшим асортиментом (вибір зберігається в **`scraper/stores.json`**, його можна змінити вручну або перевибрати: `node scraper/scrape.js --repick`). Одне місто — ~4 хв, два міста збираються паралельно.
  - лише одне місто: `node scraper/scrape.js --city Хмельницький`
- **`scraper/groups.js`** — розділи («надкатегорії») для товарів: беруться з меню atbmarket.com, плюс ручні відповідності для категорій, яких у меню немає. Товари без відповідності потрапляють у розділ «Інше» — тоді додайте категорію в `EXTRA`.
- **`scraper/silpo.js`** — каталог Сільпо для тестової копії сайту (`/test/`): по одному магазину в кожному нашому місті, де є Сільпо (магазини запам'ятовані в `scraper/silpo-stores.json`), з відкритого API silpo.ua. Результат — `site/data/chains/silpo/<місто>/` у тому самому форматі, що й АТБ. Мапу рівня цін Сільпо (`site/data/chains/silpo/levels.json`) будує `scraper/silpo-snapshot.js` щонеділі.
- **`scripts/daily.ps1`** — pull → збір АТБ → збір Сільпо (його збій не зриває публікацію АТБ) → коміт → push. Журнал пишеться в `daily.log`.
- **`scripts/install-task.ps1`** — реєструє щоденне завдання «ATB Price» у Планувальнику завдань.
- **`site/data/cities.json`** — список міст з даними (з координатами центрів).
- **`site/data/ukraine.json`** — контури областей України для мапи «Ціна в інших містах»: спрощені межі з Natural Earth (ne_10m_admin_1, суспільне надбання), уже в проєкції сайту. Статичний файл, щодня не змінюється.
- **`site/data/levels.json`** — рівень цін у ~350 містах АТБ для мапи на головній: на скільки % дорожче чи дешевше за середнє. Будує `scraper/snapshot.js` (по одному магазину й 6 розділів у кожному місті, ≈45 хв) щонеділі після щоденного збору; координати міст, яких немає в `cities.js`, — у `scraper/coords.json` (GeoNames).
- **`site/data/compare/NN.json`** — ціни кожного товару в усіх містах (для порівняння на сторінці товару), розбиті за `id % 100`. Будує **`scraper/compare.js`** під час публікації (GitHub Actions) і після збору локально; у git не зберігається.
- **`site/data/cities/<місто>/extra.json`** — спільний каталог: товари, яких у місті немає, з цінами найближчого (по прямій між центрами міст) міста, де вони є (поле `from`). Будує **`scraper/fallback.js`** так само, як і порівняння; у git не зберігається.
- **`site/data/cities/<місто>/products.json`** — поточний каталог міста (для пошуку і карток). Товари, яких сьогодні немає в каталозі магазину, лишаються тут ще 30 днів (службове поле `out`); їхню ціну парсер звіряє зі сторінки товару (до 60 на місто за збір). На сайті наявність не показується.
- **`site/data/cities/<місто>/changes.json`** — що змінилося в останньому зборі порівняно з попереднім днем (стрічка «Що змінилося»: подешевшало, подорожчало, нові акції, акція закінчилась, нові товари). Будує **`scraper/changes.js`**.
- **`site/data/cities/<місто>/history/NN.json`** — історія цін міста, розбита на 100 файлів за `id % 100`. Зберігаються лише **зміни**: `[дата, ціна]` або `[дата, ціна, ціна_без_акції]` — товар у наявності; `[дата, ціна, ціна_без_акції | null, 1]` — товару немає в наявності, ціну взято зі сторінки товару (парсер перевіряє до 60 таких сторінок на місто за збір); `[дата, null]` — немає в наявності, ціна невідома. П'яте поле — ціна при оплаті карткою АТБ: `[дата, ціна, null, 0, ціна_з_карткою]`.
- **`site/`** — статичний сайт на чистому JS без збірки. Графік намальовано вручну через SVG.
- **Обране і сповіщення** працюють без сервера: обране зберігається в браузері (`localStorage`), подешевшання видно на сторінці «Обране» і на значку ♥. Системні сповіщення надсилає service worker (`site/sw.js`) через Periodic Background Sync — це працює в Chrome/Edge, коли сайт встановлено як застосунок; браузер сам вирішує, як часто перевіряти (приблизно раз на день).

## Локальний запуск

```bash
npm install
npm run scrape   # зібрати ціни (~5–10 хв)
npm run serve    # відкрити сайт на http://localhost:3000
```

## Публікація на GitHub

1. Створіть репозиторій на GitHub і запуште проєкт.
2. **Settings → Pages → Source: GitHub Actions.**
3. Зареєструйте щоденний збір (один раз):
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install-task.ps1
   ```

Далі все працює саме: щодня комп'ютер збирає ціни й пушить їх, а GitHub оновлює сайт. Якщо комп'ютер о 05:30 вимкнений, збір запуститься, щойно його увімкнуть.

Видалити завдання: `Unregister-ScheduledTask -TaskName 'ATB Price'`.

## Обмеження

- Ціни беруться для одного магазину в кожному місті; в інших магазинах того ж міста асортимент і ціни можуть трохи відрізнятися.
- Історія накопичується від першого запуску.
- Якщо АТБ змінить верстку сайту, треба буде поправити `parseCards()` у парсері.
